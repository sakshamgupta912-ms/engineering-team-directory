# Engineering Team Directory

Welcome to the engineering team. Before receiving access to company resources, every engineer must add a profile to the team directory.

This collaborative lab introduces GitHub fundamentals, GitHub CLI, GitHub Actions, and CI/CD through a realistic pull request workflow.

## Your mission

Create your engineer profile, pass the automated checks, and merge it into the directory.

### 1. Get the repository

Install [GitHub CLI](https://cli.github.com/), then authenticate and clone the repository:

```bash
gh auth login
gh repo clone https://github.com/sakshamgupta912-ms/engineering-team-directory.git
```

Replace `OWNER` with the instructor's GitHub organization or username.

### 2. Create a branch

```bash
git switch -c profile/YOUR-GITHUB-USERNAME
```

### 3. Add your profile

Copy `profiles/sample.md` to `profiles/YOUR-GITHUB-USERNAME.md`. Keep the field names unchanged and replace every value with your information.

```markdown
name: Your Name  
github: your-github-username  
role: Your Role  
location: City, Country  
skills: Skill One, Skill Two, Skill Three  
bio: Write a short introduction about yourself here.
```

Every line uses the simple `key: value` format. Keep the two spaces at the end of each line except the last one so Markdown viewers display every field on a separate line. Required fields are `name`, `github`, `role`, `location`, `skills`, and `bio`. The filename must match the GitHub username in the profile.

### 4. Validate your work

Node.js 22 or newer is recommended. No packages need to be installed.

```bash
npm test
```

Open `index.html` in a browser to preview the directory.

### 5. Commit and push

```bash
git add profiles/YOUR-GITHUB-USERNAME.md
git commit -m "Add YOUR-NAME to engineering directory"
git push -u origin profile/YOUR-GITHUB-USERNAME
```

### 6. Open and monitor a pull request

```bash
gh pr create --fill
gh pr checks --watch
gh pr view --web
```

If validation fails, read the error in the Actions log, fix the profile, commit, and push again. The same pull request updates automatically.

## What the automation does

- **Continuous integration:** `.github/workflows/validate-profiles.yml` checks every profile pull request.
- **Continuous deployment:** `.github/workflows/deploy-pages.yml` rebuilds and deploys the directory after changes reach `main`.
- **Directory build:** `scripts/build-profiles.js` validates Markdown files and generates `assets/profiles-data.js` for the website.

## Instructor setup

1. Create a new GitHub repository and push these files to its `main` branch.
2. In **Settings > Pages**, set **Source** to **GitHub Actions**.
3. In **Settings > Branches**, protect `main`: require a pull request and require the `validate` status check.
4. Give participants write access, or use forks if organization policy requires them.
5. Run the first **Deploy directory** workflow manually to publish the initial site.

For a group of 25, split participants into review pairs. Ask each participant to review and approve their partner's profile before merging.
